MUR M26 Race Car

Melbourne University Racing · finished and driving

Working with embedded systems for the first time, I led a team of 7 to design, implement and test software for the MUR M26 race car. I was responsible for the ECU logic, as well as the final integration of all components into the monorepo.

Highlights

  • The M26 is finished and driving.
  • Firmware and a wireless telemetry service for an electric Formula SAE car.
  • Integrated the CAN buses across the car, working with the other sub-teams.
  • Built for Formula SAE-A at Tailem Bend, South Australia.

Built with

C · Zephyr RTOS · Python · Embedded Systems

Basketball Predictor

Machine learning · live API

An ML based basketball outcome predictor that leverages advanced metrics to forecast NBA game results and identify betting value by comparing fair and market odds.

Highlights

  • Two win-probability models side by side: logistic and normal.
  • Converts probabilities to fair odds and flags games where the market is longer.
  • A GitHub Actions job runs the model three times a day and publishes the picks to Predictor.app.

Built with

Python · nba_api · GitHub Actions · JSON

AI Snake Player
