Snake AI

A Deep Q-Network agent that learns to play Snake, running live in your browser. I originally built this in Python using PyTorch and PyGame, and this page runs a JavaScript port of the same game, network and training loop. You can watch the trained agent, train a new one from scratch, or play the game yourself.

Use the arrow keys or WASD to steer and Space to pause. On mobile, swipe on the board.

How It Works

DQN

What the agent sees

The agent doesn't see the whole board. Instead it gets 11 simple inputs: whether there's danger straight ahead, to the right or to the left, which direction it's moving, and whether the food is left, right, above or below it. This keeps training fast, but it also means the agent can't plan ahead and will sometimes trap itself.

The network

A simple neural network with one hidden layer takes the 11 inputs and outputs a Q-value (expected future reward) for each of the three possible moves: go straight, turn right or turn left. The agent picks the move with the highest value.

11 inputs 256 ReLU 3 Q-values

Rewards & learning

The agent gets +10 for eating food and −10 for dying. A game also ends if the snake goes 100 × its length frames without eating, to stop it from learning to loop forever. After each move, the network is trained towards the Bellman target:

Q(s, a) ← r + γ · maxa′ Q(s′, a′)

Training setup

  • γ = 0.9: discount on future rewards
  • ε = (80 − games) / 201: chance of a random move, which drops to 0 after 80 games
  • Adam, lr = 0.001: optimiser, with MSE loss
  • Replay memory 100k: a batch of 1000 past moves is trained on after each game
